# Handover demo

Two versions of the same story: a **3-minute live demo** for round one, and a **1-minute video** for the
submission. Same beats, same data, so we only rehearse one thing.

**The story:** Dana runs payments operations at Northgate Bank (fictional) and is retiring. Sam is taking over.
Handover interviews Dana before she leaves, catches where her answers don't add up, and hands Sam what he is
allowed to inherit, in her own voice. Each thing Dana knows is based on a real incident (see RESEARCH.md).

**Voices:** the interviewer, Dana and Sam are three different stock ElevenLabs voices, generated by
`demo/generate_audio.py`. Nobody's real voice is cloned. Say this out loud if anyone asks.

**Roles:** one **Speaker** who talks the whole time, and one **Driver** who only clicks. Don't combine them.

## Questions judges will grill us on

**"Why not just have AI read the code and docs?"**
The backup-screen zeros, the R7 flag and the Halvorsen deal weren't in any code or doc. They were in people's
heads. Klarna and Commonwealth Bank both cut staff for AI in the last two years and then reversed it. AI agents
need this context. Handover is how they get it, with rules about who can use it.

**"How do you know nothing leaks?"**
The permission filter runs inside the `$vectorSearch` stage itself, so memories you can't see are never even
candidates. They can't reach the prompt. We also count blocked hits without returning their text, and every
read goes to the audit log.

**"How do you prove memory changed behavior?"**
The same question with memory on vs off gives a different answer, and the LangSmith trace names the exact memory
ids that caused it.

**"Isn't storing the Halvorsen deal itself a risk?"**
It's never_transfer, so only Dana can see it, and every access is audited. In a real bank that is the point:
an undocumented exception to a control is exactly what compliance needs to find. Today it lives only in Dana's
head.

**"Is that Dana's real voice?"**
Dana is fictional, so her voice is a stock ElevenLabs voice. In production these are the expert's real
recordings. We only synthesize the interviewer, and we never clone anyone.

**"What happens when a memory is wrong?"**
Correct makes a new version linked to the old one, and anything built from it is flagged for review. Forget
removes it and everything derived from it in one transaction, with an audit entry.
